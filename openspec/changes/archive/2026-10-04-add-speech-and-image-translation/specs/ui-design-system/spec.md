## MODIFIED Requirements

### Requirement: 应用外壳
Web 前端 SHALL 提供可折叠的图标侧边栏（折叠状态持久化）、显示当前位置的面包屑、主题切换和用户菜单。导航项 MUST 按角色显示，当前路由 MUST 高亮，并带有指示条的位移动画。

#### Scenario: 折叠侧边栏
- **WHEN** 用户点击折叠按钮
- **THEN** 侧边栏以动画收窄为只显示图标，悬停图标时显示名称提示；刷新后保持折叠

#### Scenario: 普通用户导航
- **WHEN** USER 角色用户登录
- **THEN** 侧边栏的「翻译」分组依次显示「翻译工作台」「同声传译」「图片翻译」「文档翻译」「翻译历史」「术语库」「翻译记忆」，不显示管理分组
