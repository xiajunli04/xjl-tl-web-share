## ADDED Requirements

### Requirement: 翻译记录持久化
系统 SHALL 为每次成功完成的翻译保存一条记录：原文、译文、源语言、识别出的语种、目标语言、模式、实际路径、风格、领域、所用术语库与模型、评审分与修正轮次、术语命中与遵循结果、token 用量、总耗时和创建时间。同时 SHALL 按执行顺序保存每个 Agent 节点的轨迹：节点名、状态、中文摘要、详情（JSON）、耗时和 token 用量。

#### Scenario: 标准路径记录完整轨迹
- **WHEN** 一次经过 1 轮修正的标准路径翻译完成
- **THEN** 记录的 `reviewRounds=1`，轨迹按 seq 顺序包含 analyze、plan、retrieve、translate、review、refine、review、finalize

#### Scenario: 失败的翻译不入库
- **WHEN** 翻译以 error 事件结束
- **THEN** 不产生翻译记录

### Requirement: 历史检索
系统 SHALL 允许用户分页查询自己的翻译历史，支持按关键词（匹配原文或译文）、源语言、目标语言、是否收藏和时间范围筛选，按创建时间倒序排列。用户 MUST 只能看到自己的记录。

#### Scenario: 关键词检索
- **WHEN** 用户搜索 "神经网络"
- **THEN** 返回原文或译文包含该词的记录

#### Scenario: 隔离他人记录
- **WHEN** 用户 A 请求用户 B 的某条记录详情
- **THEN** 系统返回 HTTP 404、code `A0404`

### Requirement: 收藏与删除
系统 SHALL 允许用户收藏或取消收藏记录，以及逻辑删除记录。被删除的记录 MUST 不再出现在历史列表和详情中。

#### Scenario: 收藏后筛选
- **WHEN** 用户收藏一条记录后按"只看收藏"筛选
- **THEN** 列表中包含该记录

### Requirement: 历史详情与轨迹回放
历史页面 SHALL 以列表展示记录（原文/译文预览、语言对、评审分、收藏、时间），点击后在侧滑面板中以标签页展示：原文译文对照、Agent 轨迹回放（时间线按节点顺序动画重放，可查看每个节点的耗时、token 和详情）、术语命中与遵循情况。用户 SHALL 可以从详情中"在工作台中打开"，把原文和设置带回工作台。

#### Scenario: 回放轨迹
- **WHEN** 用户在详情中切换到「Agent 轨迹」标签页并点击回放
- **THEN** 时间线按记录的节点顺序依次点亮，每个节点显示耗时和 token

#### Scenario: 在工作台中打开
- **WHEN** 用户在详情中点击「在工作台中打开」
- **THEN** 跳转到工作台，原文、语言对、风格、领域和术语库都已按该记录填好
