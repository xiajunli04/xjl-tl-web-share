## ADDED Requirements

### Requirement: 设计令牌与主题
Web 前端 SHALL 通过统一的设计令牌（颜色、圆角、阴影、间距、字体）构建界面，组件 MUST NOT 硬编码颜色值。系统 SHALL 支持亮色、暗色和跟随系统三种主题，用户的选择 MUST 持久化，刷新页面时 MUST NOT 出现主题闪烁。

#### Scenario: 切换暗色模式
- **WHEN** 用户在顶栏把主题切换为暗色
- **THEN** 全站立即切换为暗色配色并带有过渡效果；刷新页面后仍为暗色，且首屏不闪白

#### Scenario: 跟随系统
- **WHEN** 用户选择"跟随系统"，并把操作系统切换为暗色
- **THEN** 页面自动切换为暗色

### Requirement: 动效规范
Web 前端 SHALL 为路由切换、列表与卡片进场、浮层与抽屉开合、数值变化、状态切换和加载状态提供统一的动效组件，时长和缓动 MUST 一致且克制。当用户开启系统的"减少动效"设置时，系统 MUST 只保留透明度过渡，禁用位移和缩放动画。

#### Scenario: 路由切换动效
- **WHEN** 用户从「翻译历史」切换到「术语库」
- **THEN** 新页面内容以淡入并轻微上移的方式进场（约 220ms）

#### Scenario: 尊重减少动效
- **WHEN** 用户的操作系统开启了"减少动效"，并访问任意页面
- **THEN** 页面切换、列表进场只有透明度变化，没有位移动画

### Requirement: 信息分层，禁止整页平铺
Web 前端的每个页面 SHALL 按任务把信息分层组织（标签页、分步对话框、侧滑详情、可折叠分区、主从布局、弹层），MUST NOT 把多组表单、表格和详情从上到下堆叠在同一个长页面中。详情查看与编辑 SHALL 优先使用侧滑面板或对话框，在不离开列表上下文的前提下完成。

#### Scenario: 日志页面分层
- **WHEN** 管理员打开日志页面
- **THEN** 登录日志与操作日志以两个标签页呈现；点击某条操作日志时在侧滑面板中查看完整参数，而不是在页面中展开长文本

#### Scenario: 个人中心分层
- **WHEN** 用户打开个人中心
- **THEN** 「基本资料」与「安全设置」分属两个标签页，同一时刻只显示一个表单

### Requirement: 加载、空和错误状态
所有数据视图 SHALL 在加载时显示与最终布局一致的骨架屏，在没有数据时显示带说明和主操作的空状态，在请求失败时显示带错误码、traceId 和重试按钮的错误状态。

#### Scenario: 空术语库列表
- **WHEN** 新用户第一次打开术语库页面，没有任何术语库
- **THEN** 页面显示空状态插画、说明文字和「新建术语库」按钮

#### Scenario: 加载失败
- **WHEN** 历史列表请求返回 B0001
- **THEN** 列表区域显示错误状态，包含错误码、可复制的 traceId 和「重试」按钮

### Requirement: 应用外壳
Web 前端 SHALL 提供可折叠的图标侧边栏（折叠状态持久化）、显示当前位置的面包屑、主题切换和用户菜单。导航项 MUST 按角色显示，当前路由 MUST 高亮，并带有指示条的位移动画。

#### Scenario: 折叠侧边栏
- **WHEN** 用户点击折叠按钮
- **THEN** 侧边栏以动画收窄为只显示图标，悬停图标时显示名称提示；刷新后保持折叠

#### Scenario: 普通用户导航
- **WHEN** USER 角色用户登录
- **THEN** 侧边栏显示「翻译工作台」「翻译历史」「术语库」，不显示管理分组
