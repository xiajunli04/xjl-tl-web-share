## Context

- ⑧ 的数字人：`AiAvatar` 外壳（状态与降级判断）加上 R3F/three-vrm 的 `avatar-canvas`。口型由 `lib/avatar/lipsync.ts` 根据播放输出的频谱计算 `aa/ih/ou/ee/oh` 权重，状态由 `deriveAvatarState` 判定，同传通过 `useInterpretAvatar()` 提供信号。
- 用户要求与概念图 1:1 一致、去掉耳机、先做中英日韩。网关只有图像模型（`nano-banana-pro` 等），没有视频模型。
- 技术验证（2026-10-05）：在底图上用“只改嘴部”的编辑提示，生成张嘴变体。像素差分显示：背景平均差 3.5，衣服 15，眼睛 7.7，嘴部 35+，热力图上只有嘴部是亮的。也就是说，编辑能保持整体对齐，局部替换可行。

## Goals / Non-Goals

**Goals：**
- 画面就是概念立绘本身（1:1），并在实时状态下自然地“活”起来：说话开口、眨眼、思考抬眼、倾听前倾、指针视差、呼吸。
- 资源可复现：提示词与生成、构建脚本入库，新增一个语言形象只需运行两条命令。
- 加载期间与降级时显示的都是同一张立绘，不再出现“光球 → 人物”的跳变。

**Non-Goals：** 见 proposal「非目标」。

## Decisions

### D1 渲染：单个 three.js 着色器四边形，图集叠加

- **决策**：使用原生 three.js（`WebGLRenderer` + 正交相机 + 一个平面 + `ShaderMaterial`），不再引入 R3F。片元着色器的处理顺序：
  1. 按 `uView`（当前构图在立绘中的子矩形）把屏幕 uv 映射到立绘 uv；
  2. 叠加呼吸缩放（以底部中心为原点，幅度 ±0.3%）；
  3. 深度视差：`uv' = uv + uOffset · (depth(uv) − 0.35)`；
  4. 采样 `base`（RGBA，alpha 来自抠像蒙版）；
  5. 依次叠加至多 8 个局部图层：每层在立绘中有目标矩形 `dst`，在图集中有源矩形 `src`，再乘以权重 `w`，按图层 alpha × w 混合；
  6. 输出预乘 alpha，背景透明。
- 一张图集纹理容纳全部局部图层，一个形象总共 3 张纹理（base、depth、atlas），一次绘制完成。
- **备选方案**：
  - Canvas2D 逐帧合成后上传纹理：每帧上传约 5 MB，成本过高；
  - 每个图层一张纹理：会受纹理单元数量限制，状态也更复杂。
- **理由**：画面就是原图，GPU 成本极低，并且视差只能在着色器里实现。

### D2 资源流水线：生成 → 差分提取 → 图集

- `generate.py`：对每个形象生成 `base`，以及 `mouth-small/aa/oh/ee`、`eyes-closed`、`eyes-up`、`happy`、`matte`、`depth`。
  - 提示词统一要求“只改局部，其余像素保持不变”；
  - 失败自动重试 3 次；
  - 原图存在 `web/.avatar-src/`，不入库。
- `build.py` 的处理步骤：
  1. 由 `mouth-aa` 与 `eyes-closed` 的强差分质心得到嘴部与眼部中心，确定各自的搜索窗口；
  2. 对每个局部变体，在窗口内计算模糊后的差分，阈值化后膨胀 6 px、羽化 10 px，作为 alpha，按包围盒裁切（`happy` 取嘴、眼窗口的并集）；
  3. 在掩膜外环上计算变体与底图的逐通道增益，做颜色校正，消除整体色偏；
  4. 把各图层装箱成 `atlas.webp`；把 `base` 的 RGB 与 `matte` 合成为带 alpha 的 `base.webp`（长边 1600）；深度图压成 512 px 的 `depth.webp`；
  5. 输出 `manifest.json`，内容包括：`size`、`face` 矩形（用于头肩构图）、`layers[{name, dst, src}]`（归一化坐标），以及可选的 `mouth`/`eyes` 中心。
- **理由**：变体与底图整体对齐，但有轻微的重绘噪声，只取局部并羽化就能避免整张图闪烁。颜色校正可以消除局部色差。

### D3 状态到图层权重

纯函数 `lib/avatar/rig-weights.ts`，按帧计算：
- **嘴型**：`open = max(visemes)`。
  - `open < 0.12` 时闭口；`< 0.32` 时为 small；
  - 否则按主导口型选择：`oh/ou → oh`，`ee/ih → ee`，`aa → aa`；
  - 目标帧权重以时间常数 45 ms 趋近 1，其余帧趋近 0（交叉淡化，避免出现双唇重影）；
  - 浏览器朗读兜底时使用 `pseudoVisemes`。
- **眨眼**：每隔 2.5–6 s 一次，0 → 1 → 0，用时 140 ms；thinking 状态下不眨眼。
- **思考**：`eyes-up` 以 250 ms 趋近 1。
- **开心**：首次就绪或点击时，`happy` 持续 1.2 s，同时让轻跳偏移以 3 s 为冷却。
- **运动**：
  - 指针视差 `offset = pointer × 0.012`；
  - idle 时缓慢摇摆（±0.004）；
  - listening 时放大 1.2% 并配合点头；
  - speaking 时根据输出能量轻点头；
  - error 时整体降低饱和度。

### D4 形象与语言

`lib/avatar/characters.ts` 是形象清单：`{id, lang, label, outfit}`。`characterForLang(lang)` 根据语言选择形象，没有专属形象时回退到 `zh`。
- AI 对话：使用对话语言（aiLang）的形象。
- 双向对话：使用 B 侧（对方）语言的形象。
- 首页：提供四个切换芯片。
- 设置步骤：对话语言旁显示形象预览。
- 名字统一为 Lumi，后端不需要改动。

### D5 加载与降级

- `AiAvatar` 先渲染静态立绘：一个 `div` 使用 `base.webp` 作为背景，并按构图计算 `background-size/position`，作为 LCP 友好的占位。
- 同时懒加载 `portrait-rig` chunk（three.js）和 atlas、depth 两张纹理，就绪后用 300 ms 交叉淡入画布。
- 降级为静态立绘的条件：偏好为“静态”、开启“减少动效”、不支持 WebGL、资源加载失败，或运行中帧率持续低于 24（沿用 `createFpsMonitor`）。静态立绘保留状态光环（倾听为绿色、思考为蓝色、说话为品牌色）和 aria-live 说明。
- 删除光球。模式卡片的 AI 对话插画改为四个形象的圆形头像。
- 偏好字段 `avatarStyle: "live" | "static"`；持久化时把旧值 `"3d"` 映射为 `"live"`、`"simple"` 映射为 `"static"`。

### D6 构图

`framing="bust"` 时，构图为立绘全幅按容器比例做 cover，焦点在 `face` 中心偏下。`framing="portrait"` 时，构图为以 `face` 为中心、高约 2.2 倍脸高的子矩形，用于圆形徽章。着色器和静态背景共用同一套 `viewRect` 计算（纯函数，可单测）。

## UI/UX

### 信息架构
- **AI 对话进行中**：布局不变，左侧舞台换成立绘，有渐变背景与柔光，人物底部与舞台融合淡出。顶部场景徽章与语言徽章保留。
- **AI 对话设置**：在“和 Lumi 说的语言”下方显示该语言对应形象的头像与服饰说明；切换语言时头像交叉淡入。
- **双向对话**：徽章使用 B 侧形象的头肩构图。
- **首页「和 AI 面对面」**：舞台右上角提供“中 / EN / 日 / 한”四个形象芯片。切换时人物交叉淡入，开场白改用该语言朗读并显示对应字幕。
- **模式卡片**：AI 对话卡片的插画改为四个形象圆形头像的堆叠。

### 动效清单

| 场景 | 动效 | reduced-motion |
|---|---|---|
| 立绘就绪 | 静态图 → 动态画布交叉淡入 300 ms | 保持静态 |
| 说话 | 嘴型帧交叉淡化（45 ms），随输出能量轻点头 | 静态立绘 + 品牌色光环 |
| 眨眼 | 每 2.5–6 s 一次，140 ms | 无 |
| 思考 | 视线上移（250 ms 淡入）、轻微歪头视差 | 蓝色光环 |
| 倾听 | 前倾放大 1.2%、点头，视差随麦克风电平变化 | 绿色光环 |
| 指针 | 深度视差，阻尼 120 ms | 无 |
| 点击 / 首次就绪 | 开心表情 1.2 s + 轻跳 | 无 |
| 切换形象 | 交叉淡入 400 ms | 仅透明度 |

## Risks / Trade-offs

- [编辑变体出现局部错位或色差] → 只取局部窗口，配合颜色校正与羽化；生成脚本可单独重生成某个变体（`--force` 加变体名）；构建时输出叠加预览图供人工检查。
- [AI 生成的抠像蒙版发丝边缘粗糙] → 立绘底部与边缘再加一层渐隐；浅色舞台背景与原背景接近，可以掩盖边缘；必要时退回不透明底图（manifest 中 `matte:false`）。
- [只有离散嘴型帧，口型不如 3D 连续] → 交叉淡化，并让嘴型帧率与音节节奏匹配；二次元风格对离散口型的接受度较高。
- [深度图失真导致视差拉伸] → 视差幅度上限 1.2%，深度先做 8 px 模糊平滑。
- [资源体积] → 每个形象的 base 约 250 KB、atlas 约 150 KB、depth 约 30 KB；四个形象合计约 1.8 MB，远小于原来的 6 MB VRM，且按需加载。

## Migration Plan

纯前端替换，不涉及后端与数据：
- 删除 VRM 依赖与资源；
- 偏好值兼容映射（见 D5）；
- 回滚：revert 本变更的提交即可。
