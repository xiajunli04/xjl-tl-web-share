# 在新电脑上运行译桥 · LinguaBridge

本文说明如何在一台新电脑（Windows / macOS / Linux）上把项目完整跑起来，以及常见问题的处理办法。
按顺序做完第 1–6 节即可使用；第 7 节是可选功能，第 8 节是排障。

> 项目由三个服务组成，**都要启动**：
> - **Python AI 服务**（端口 8000）：翻译 Agent、语音识别、同传；
> - **Spring 后端**（缺省端口 8080）：登录、管理后台、数据；
> - **前端**（缺省端口 3000）。
>
> 另外需要 Docker 里的 PostgreSQL 和 Redis。

---

## 1. 安装软件

| 软件 | 版本 | 说明 |
|---|---|---|
| Docker Desktop | 最新版 | 运行 PostgreSQL 与 Redis |
| JDK | **25** | 不用改系统的 `JAVA_HOME`，启动 Spring 时临时指定即可 |
| Python | **3.12** 及以上 | 另装 [uv](https://docs.astral.sh/uv/)（Python 依赖管理工具） |
| Node.js | 22 及以上 | 另装 pnpm 10：`npm install -g pnpm` |
| Git | 任意 | Windows 上 Git for Windows 自带 openssl，局域网 HTTPS 会用到 |

安装后在终端检查：`docker --version`、`java -version`（或 JDK 目录下的 `bin/java -version`）、`uv --version`、`node -v`、`pnpm -v`。

## 2. 准备配置文件

```bash
# 在项目根目录
cp .env.example .env
cp web/.env.example web/.env.local
```

打开 `.env`，**至少修改下面 4 项**（不要沿用示例值）：

| 变量 | 作用 | 生成方法 |
|---|---|---|
| `JWT_SECRET` | 登录令牌签名 | `openssl rand -base64 48` |
| `MODEL_KEY_SECRET` | 加密数据库里保存的模型 API Key | `openssl rand -base64 32` |
| `INTERNAL_TOKEN` | Spring 与 Python 之间的内部鉴权 | 任意长随机字符串 |
| `ADMIN_PASSWORD` | 首个管理员账号的密码 | 自定 |

注意：

- `.env` 含密钥，**不要提交到 Git、不要发给别人**；每台电脑各自生成。
- 如果要把另一台电脑的**数据库整体迁移**过来，`MODEL_KEY_SECRET` 必须与原来的一致，否则已保存的模型 API Key 无法解密，需要在后台重新填写。

## 3. 启动数据库

```bash
docker compose up -d
docker compose ps        # postgres 与 redis 都应为 healthy
```

- Redis 映射到宿主机 **6380** 端口（避免和本机已有的 Redis 冲突），`.env` 里的 `REDIS_PORT` 保持 6380。
- 拉取镜像超时：给 Docker 配置镜像加速器后重试（镜像为 `pgvector/pgvector:pg17` 和 `redis:7-alpine`）。

## 4. 下载本地模型（首次，一次性）

同传、语音输入需要本地语音模型；翻译记忆需要 embedding 模型。在国内建议先在 `.env` 中打开镜像：

```bash
# .env（国内网络建议设置）
SPEECH_MODEL_MIRROR=https://ghfast.top/https://github.com   # 语音识别模型（GitHub）
SPEECH_HF_MIRROR=https://hf-mirror.com                      # 断句判定模型（HuggingFace，可选）
HF_ENDPOINT=https://hf-mirror.com                           # 翻译记忆的 embedding 模型
```

然后：

```bash
cd python-backend
uv sync                                   # 安装依赖
uv run python -m app.speech.download      # 下载语音模型（约 240 MB，存到 python-backend/.cache/speech/）
```

- 下载命令可以重复执行，已下载的会跳过。
- embedding 模型（数百 MB，存到 `python-backend/.cache/models/`）在 Python 服务第一次启动时自动下载，第一次启动会慢一些。
- `uv sync` 时连接 PyPI 不稳定：可临时使用镜像，例如 `uv sync --index-url https://mirrors.aliyun.com/pypi/simple`。

## 5. 启动三个服务

每个服务开一个终端窗口，按顺序启动。

```bash
# ① Python AI 服务（端口 8000）——必须用这条命令启动（Windows 上会自动使用兼容的事件循环）
cd python-backend
uv run python -m app --port 8000

# ② Spring 后端——必须在 springboot-backend 目录内启动（它从上一级目录读取 .env）
cd springboot-backend
JAVA_HOME=/path/to/jdk-25 ./mvnw spring-boot:run
#   Windows PowerShell：$env:JAVA_HOME="D:\jdk-25"; .\mvnw.cmd spring-boot:run

# ③ 前端
cd web
pnpm install
pnpm dev
```

看到以下输出说明启动成功：

- Python：`Application startup complete.`
- Spring：`Started TlApplication`（首次启动会自动建表并创建管理员）
- 前端：`Ready`

浏览器打开 http://localhost:3000，用 `.env` 中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 登录。

**端口被占用时**（例如 8080 已被其他程序使用）：

1. `.env` 中设置 `SERVER_PORT=18080`；
2. `web/.env.local` 中设置 `API_PROXY_TARGET=http://localhost:18080`，`NEXT_PUBLIC_API_BASE_URL` 留空；
3. 前端换端口：`pnpm dev --port 3001`，并把 `.env` 的 `WEB_ORIGIN` 改为 `http://localhost:3001`；
4. 重启 Spring 与前端。

## 6. 在管理后台配置模型（新数据库必做）

**大模型的地址和 API Key 存在数据库里，不在 `.env` 里。** 新电脑的数据库是空的，需要重新添加：

1. 登录后进入「管理后台 → 模型配置」；
2. 添加至少一个**对话模型（CHAT）**，提供方选"OpenAI 兼容"（或 Anthropic），填写 Base URL、模型名、API Key；
3. 点「测试连通性」，成功后设为**默认**；
4. 可选：添加语音识别（ASR）、语音合成（TTS）、实时同传、图片翻译、实时语音对话等能力的模型。

完成后在「翻译工作台」输入一句话测试，几秒内应出现译文。

## 7. 可选功能

### 7.1 手机 / 局域网访问（同传需要麦克风）

浏览器只在 **HTTPS 或 localhost** 下允许使用麦克风，所以手机访问要用：

```bash
cd web
pnpm dev:lan            # 缺省端口 3001，可加 --port 3002
```

- 终端会打印 `https://本机局域网IP:3001`，手机连同一个 Wi-Fi 后打开这个地址；
- 首次打开会提示"证书不受信任"（自签名证书，仅用于本地开发），选择"高级 → 继续访问"；
- **防火墙**：Windows 首次运行时允许 Node.js 访问"专用网络"；如果手机打不开，在防火墙中放行该端口的入站连接；
- 用 http 地址打开时手机无法录音：会议室会以"仅收听"方式加入，其他模式会提示改用 https。

### 7.2 语音播报

缺省使用微软 Edge 在线语音合成（需要能访问互联网）；不可用时自动改用浏览器自带朗读，不影响使用。

### 7.3 断句判定模型（Smart Turn）

同传断句缺省只用文本规则。说话停顿多、经常被切成两句时，可以在 `.env` 中设置 `ENDPOINT_SMART_TURN=auto` 后重启 Python
（模型已由第 4 步的下载命令一并下载，约 9 MB）。开启后断句更准，但每句约多等 0.15 秒。

## 8. 常见问题

### 网络、代理与证书

**本项目不需要为网络环境改代码。** 访问大模型时，证书由 Python 标准库在本机校验：信任操作系统的证书库，以及随依赖安装的 certifi 公共根证书，校验过程中不需要联网。

只有以下情况需要额外配置：

| 情况 | 现象 | 处理 |
|---|---|---|
| 需要通过 HTTP 代理才能访问外网 | 模型「测试连通性」超时 | 启动 Python 前设置环境变量 `HTTPS_PROXY=http://代理地址:端口`（`NO_PROXY=localhost,127.0.0.1`） |
| 公司 / 学校网络会替换 HTTPS 证书（安全网关、抓包代理） | 连通性测试报 `CERTIFICATE_VERIFY_FAILED` | Windows：把网关的根证书导入"受信任的根证书颁发机构"；macOS / Linux：设置 `SSL_CERT_FILE=/path/to/ca-bundle.pem`（包含网关根证书的证书文件）后重启 Python |
| 模型服务用的是自签名证书 | 同上 | 同上，把它的根证书加入系统证书库或 `SSL_CERT_FILE` |
| macOS 用 python.org 安装的 Python | 访问部分网站证书错误 | 运行一次 `/Applications/Python 3.12/Install Certificates.command` |

> 背景：早期版本中，大模型 SDK 在 Windows 上会联网校验证书。网络或代理卡住时，整个 AI 服务都会失去响应，翻译页面一直显示"运行中"。这个问题已在代码中修复（`python-backend/app/core/tls.py`），换电脑不需要任何设置。

### 其他问题

| 现象 | 原因与处理 |
|---|---|
| 翻译一直"运行中"、没有结果 | ① 确认 Python 服务终端没有报错且仍在运行；② 后台「模型配置」中测试连通性；③ 网络受限时见上表配置代理 |
| Python 服务突然退出，日志末尾是 `OSError: [WinError 10055] 由于系统缓冲区空间不足或队列已满` | Windows 网络栈资源短暂紧张（常见于 Clash 等代理的 TUN 模式或 VPN）。已在代码中处理（`app/core/event_loop.py`，遇到时退避重试，日志会打印一条警告）；请确认用 `uv run python -m app` 启动。若警告频繁出现，可关闭代理的 TUN 模式或改用系统代理 + `HTTPS_PROXY` |
| 登录、翻译等请求超时，Spring 日志反复出现 `Redis command timed out` | Docker Desktop 重启过（容器被重建），Spring 仍持有旧的 Redis 连接。重启 Spring 即可；`docker compose ps` 可以看到容器的启动时间 |
| 电脑整体变卡，偶发 `fork: Resource temporarily unavailable`、Python 报 WinError 10055 | 系统内核资源被某个程序耗尽（句柄泄漏）。在任务管理器“详细信息”页添加“句柄”列排序，句柄数达到数万的进程（曾遇到电脑管家类软件约 9 万）需重启该软件或重启电脑 |
| 翻译报"LLM 调用失败"（C0120） | 模型地址、模型名或 API Key 有误，或额度用完；在「模型配置」中测试连通性查看具体错误 |
| 健康检查 / 系统状态显示 `db=DOWN`（Windows） | 没有用 `uv run python -m app` 启动；用 uvicorn 时需加 `--loop app.core.event_loop:selector_event_loop` |
| Spring 启动报数据库连接失败 | `docker compose ps` 确认容器 healthy；`.env` 的数据库端口、密码与 compose 一致 |
| 修改了 `.env` 中的数据库密码后连不上 | 数据库角色只在首次建库时创建：执行 `docker compose down -v` 重建（**会清空数据**） |
| 同传页面提示"本地识别模型未下载" | 执行第 4 步的 `uv run python -m app.speech.download` |
| Windows 上同传启动即崩溃，日志与 onnxruntime 有关 | 系统目录中自带的旧版 onnxruntime.dll 冲突；代码已处理。若仍出现，执行 `uv sync` 确认 onnxruntime 已安装后重试 |
| 手机能打开页面但点开始没反应 / 无法录音 | 必须用 `pnpm dev:lan` 打印的 **https** 地址，并在证书警告页选择继续访问 |
| 前端改了 `.env.local` 不生效 | 重启前端（`pnpm dev` / `pnpm dev:lan`） |
| 多语会议室连接失败 | 确认 Spring 在运行；前端 `API_PROXY_TARGET` 指向正确的 Spring 端口 |
